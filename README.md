# 💫 About Me:
I'm **Satyam Kale**, a full-stack developer focused on building reliable backend systems, AI-powered applications, and clean product interfaces. I enjoy designing scalable systems that go beyond basic CRUD APIs, with a focus on performance, caching using Redis, and data management with PostgreSQL and MongoDB.

I build modern web applications using **Express.js**, **Next.js**, and **TypeScript**, automate workflows with **GitHub Actions**, and deploy production-ready applications on **AWS** and **Vercel**.

I'm currently expanding my expertise in **AI development**, building **LLM-powered applications**, **RAG (Retrieval-Augmented Generation) systems**, **AI agents**, and self-hosted AI infrastructure. I enjoy exploring how AI can solve real-world problems while building systems that are scalable, maintainable, and practical.

Outside of coding, I contribute to open source, share what I learn through technical writing, and continuously explore new technologies to become a better engineer.
